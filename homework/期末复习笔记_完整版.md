## 一、线性表与链表

### 1.1 单链表基本操作

#### 核心结构定义

```c
typedef struct LNode {
    int data;
    struct LNode *next;
} LNode, *LinkList;
```

#### 关键算法

**① 在最大值结点前插入**

- **思路**：先遍历找最大值 → 再遍历找到第一个最大值结点的前驱 → 插入新结点
- **时间复杂度**：O(n)，需要两次遍历
- **应用场景**：有序链表维护、优先级队列

```c
void InsertBeforeMax(LinkList L, int x) {
    // 第一次遍历：找最大值
    LNode *p = L->next;
    int max = p->data;
    while (p != NULL) {
        if (p->data > max) max = p->data;
        p = p->next;
    }
  
    // 第二次遍历：找第一个最大值的前驱
    LNode *pre = L;
    p = L->next;
    while (p != NULL && p->data != max) {
        pre = p;
        p = p->next;
    }
  
    // 插入新结点
    LNode *newNode = (LNode *)malloc(sizeof(LNode));
    newNode->data = x;
    newNode->next = p;
    pre->next = newNode;
}
```

**② 集合差集运算（A-B）**

| 版本     | 时间复杂度 | 空间复杂度 | 适用场景   |
| -------- | ---------- | ---------- | ---------- |
| 无序列表 | O(n×m)    | O(1)       | 一般情况   |
| 有序列表 | O(n+m)     | O(1)       | 已排序数据 |

**无序列表差集**：

```c
void DiffSet_Unordered(LinkList A, LinkList B) {
    LNode *pre = A, *pa = A->next, *temp;
    while (pa != NULL) {
        if (IsExist(B, pa->data)) {  // 在B中存在则删除
            pre->next = pa->next;
            temp = pa;
            pa = pa->next;
            free(temp);
        } else {
            pre = pa;
            pa = pa->next;
        }
    }
    FreeList(&B);  // 释放B
}
```

**有序列表差集（双指针法）**：

```c
void DiffSet_Ordered(LinkList A, LinkList B) {
    LNode *pre = A, *pa = A->next, *pb = B->next, *temp;
    while (pa != NULL && pb != NULL) {
        if (pa->data < pb->data) {
            pre = pa;
            pa = pa->next;  // A中元素小，保留
        } else if (pa->data == pb->data) {
            pre->next = pa->next;  // 相等，删除A中元素
            temp = pa;
            pa = pa->next;
            free(temp);
        } else {
            pb = pb->next;  // B中元素小，移动B指针
        }
    }
    FreeList(&B);
}
```

### 1.2 HashMap应用 - 两数之和

**题目**：在数组中找到两个数，使其和等于目标值

**最优解法**：HashMap，时间复杂度O(n)

```java
public int[] twoSum(int[] nums, int target) {
    Map<Integer, Integer> map = new HashMap<>();
    for (int i = 0; i < nums.length; i++) {
        if (map.containsKey(target - nums[i])) {
            return new int[] { map.get(target - nums[i]), i };
        }
        map.put(nums[i], i);
    }
    return new int[0];
}
```

**关键点**：

- 边遍历边存储，避免重复查找
- HashMap的 `containsKey`和 `get`操作平均时间复杂度为O(1)

### 2.1 栈的基本特性

- **主要操作**：push（入栈）、pop（出栈）、peek（查看栈顶）
- **应用场景**：

  - 表达式求值
  - 括号匹配
  - 回溯算法
  - 递归转非递归

### 2.2 栈的经典应用

#### ① 柱状图中最大矩形（单调栈）

**核心思想**：维护一个递增栈，当遇到比栈顶小的元素时，计算以栈顶为高度的矩形面积

**时间复杂度**：O(n)

```cpp
int largestRectangleArea(vector<int>& heights) {
    stack<int> st;
    int ans = 0;
    heights.push_back(0);  // 哨兵
  
    for (int i = 0; i < heights.size(); i++) {
        while (!st.empty() && heights[i] < heights[st.top()]) {
            int h = heights[st.top()];
            st.pop();
            int w = st.empty() ? i : i - st.top() - 1;
            ans = max(ans, h * w);
        }
        st.push(i);
    }
    return ans;
}
```

**关键点**：

- 单调递增栈：用于找左边/右边第一个比当前小的元素
- 哨兵技巧：末尾加0确保所有元素出栈

#### ② 路径简化（栈消除相反方向）

**问题**：给定一系列移动指令，消除相反方向的移动，输出最短路径

**核心思想**：用栈存储每一步，新指令与栈顶相反则抵消

```c
// 方向定义：1-上, 2-下, 3-左, 4-右
int opposite(int a, int b) {
    return (a == 1 && b == 2) || (a == 2 && b == 1) ||
           (a == 3 && b == 4) || (a == 4 && b == 3);
}

// 处理逻辑
while (curStep > 0) {
    if (top >= 0 && opposite(curDir, stack[top].dir)) {
        // 抵消逻辑
        if (curStep < stack[top].step) {
            stack[top].step -= curStep;
            curStep = 0;
        } else if (curStep == stack[top].step) {
            top--;
            curStep = 0;
        } else {
            curStep -= stack[top].step;
            top--;
        }
    } else {
        stack[++top].dir = curDir;
        stack[top].step = curStep;
        curStep = 0;
    }
}
```

#### ③ 用栈模拟递归（阶乘计算）

**核心思想**：手动管理栈帧，保存递归参数和状态

```c
typedef struct {
    int n;              // 当前参数
    char status[20];    // 状态："n*?"表示待计算，"Calculate product"表示计算乘积
} StackFrame;

int factorial(int n) {
    SeqStack s;
    initStack(&s);
    int result = 1;
  
    push(&s, n, "n*?");
    while (!isEmpty(&s)) {
        StackFrame frame = pop(&s);
        if (strcmp(frame.status, "n*?") == 0) {
            if (frame.n <= 1) {
                result = 1;
            } else {
                push(&s, frame.n, "Calculate product");
                push(&s, frame.n - 1, "n*?");
            }
        } else if (strcmp(frame.status, "Calculate product") == 0) {
            result *= frame.n;
        }
    }
    return result;
}
```

**状态机设计**：

- `"n*?"`：递推阶段，需要继续展开
- `"Calculate product"`：回归阶段，执行乘法

### 2.3 队列的基本特性

- **先进先出（FIFO）**
- **循环队列**：解决假溢出问题
- **主要操作**：enqueue（入队）、dequeue（出队）

#### 循环队列反转

**思路**：队列 → 栈 → 队列（利用栈的反转特性）

```c
void ReverseQueue(Queue *Q) {
    int stk[N];
    int top = -1;
  
    // 队列元素全部出队入栈
    while (Q->count > 0) {
        int x = Q->data[Q->front];
        Q->front = (Q->front + 1) % N;
        Q->count--;
        stk[++top] = x;
    }
  
    // 栈元素全部出栈入队
    while (top != -1) {
        int x = stk[top--];
        Q->data[Q->rear] = x;
        Q->rear = (Q->rear + 1) % N;
        Q->count++;
    }
}
```

**时间复杂度**：O(n)
**空间复杂度**：O(n)

## 三、字符串与数组

### 3.1 滑动窗口技术

#### ① 滑动窗口最大值（单调队列）

**问题**：给定数组和窗口大小k，返回每个窗口的最大值

**核心思想**：维护一个单调递减的双端队列，队首始终是当前窗口的最大值

**时间复杂度**：O(n)

```cpp
vector<int> maxSlidingWindow(vector<int>& nums, int k) {
    deque<int> deq;  // 存储下标
    vector<int> result;
  
    for (int right = 0; right < nums.size(); right++) {
        // 移除超出窗口的元素
        while (!deq.empty() && deq.front() <= right - k) {
            deq.pop_front();
        }
      
        // 维护单调递减：移除比当前元素小的
        while (!deq.empty() && nums[deq.back()] < nums[right]) {
            deq.pop_back();
        }
      
        deq.push_back(right);
      
        // 窗口形成后记录结果
        if (right >= k - 1) {
            result.push_back(nums[deq.front()]);
        }
    }
    return result;
}
```

**关键点**：

- 队列存储**下标**而非值，便于判断是否超出窗口
- "砍头"：移除过期元素
- "砍尾"：维护单调性

#### ② 长度最小的子数组（前缀和+单调队列）//其实这个使用双指针会好一些

**问题**：找到和≥target的最短连续子数组

**核心思想**：前缀和 + 单调递增队列

```cpp
int minSubArrayLen(int target, vector<int>& nums) {
    int n = nums.size();
    vector<long long> prefix(n + 1, 0);
    for (int i = 0; i < n; i++) {
        prefix[i + 1] = prefix[i] + nums[i];
    }
  
    deque<int> dq;  // 存储前缀和下标，单调递增
    int ans = n + 1;
  
    for (int i = 0; i <= n; i++) {
        // 检查是否满足条件
        while (!dq.empty() && prefix[i] - prefix[dq.front()] >= target) {
            ans = min(ans, i - dq.front());
            dq.pop_front();
        }
      
        // 维护单调递增
        while (!dq.empty() && prefix[i] <= prefix[dq.back()]) {
            dq.pop_back();
        }
      
        dq.push_back(i);
    }
  
    return ans == n + 1 ? -1 : ans;
}
```

### 3.2 IO合法性判断（栈的应用）

**问题**：判断由'I'（入栈）和'O'（出栈）组成的序列是否合法

**规则**：

1. 任何时候'O'的数量不能超过'I'
2. 最终'I'和'O'数量必须相等

```cpp
int isLegal(char op[], int n) {
    int hasNum = 0;  // 栈中元素个数
    for (int i = 0; i < n; i++) {
        if (op[i] == 'I') {
            hasNum++;
        } else if (op[i] == 'O') {
            if (!hasNum) return 0;  // 空栈不能出栈
            hasNum--;
        }
    }
    return hasNum == 0;  // 最终栈必须为空
}
```

## 四、树与二叉树

### 4.1 二叉树基本概念

#### 树的节点定义

```cpp
struct TreeNode {
    int val;
    TreeNode *left;
    TreeNode *right;
    TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
};
```

#### 遍历方式

| 遍历方式 | 访问顺序     | 应用场景         |
| -------- | ------------ | ---------------- |
| 前序遍历 | 根→左→右   | 复制树、序列化   |
| 中序遍历 | 左→根→右   | BST排序输出      |
| 后序遍历 | 左→右→根   | 删除树、计算高度 |
| 层序遍历 | 逐层从左到右 | BFS、最短路径    |

### 4.2 二叉树的构建

#### ① 从前序和中序遍历构建二叉树

**核心思想**：

- 前序遍历的第一个元素是根节点
- 在中序遍历中找到根节点，左边是左子树，右边是右子树
- 递归构建左右子树

**时间复杂度**：O(n)

```cpp
class Solution {
    unordered_map<int, int> pos;  // 中序遍历值→索引映射
  
    TreeNode* build(vector<int>& preorder, int preL, int preR,
                   vector<int>& inorder, int inL, int inR) {
        if (preL > preR || inL > inR) return nullptr;
      
        int rootVal = preorder[preL];
        TreeNode* root = new TreeNode(rootVal);
      
        int rootIndex = pos[rootVal];
        int leftSize = rootIndex - inL;
      
        root->left = build(preorder, preL + 1, preL + leftSize,
                          inorder, inL, rootIndex - 1);
        root->right = build(preorder, preL + leftSize + 1, preR,
                           inorder, rootIndex + 1, inR);
      
        return root;
    }
  
public:
    TreeNode* buildTree(vector<int>& preorder, vector<int>& inorder) {
        int n = inorder.size();
        for (int i = 0; i < n; i++) {
            pos[inorder[i]] = i;
        }
        return build(preorder, 0, n - 1, inorder, 0, n - 1);
    }
};
```

**关键公式**：

- 左子树大小：`leftSize = rootIndex - inL`
- 左子树前序范围：`[preL+1, preL+leftSize]`
- 右子树前序范围：`[preL+leftSize+1, preR]`

#### ② 从层序遍历构建二叉树

**核心思想**：使用队列，按层序依次连接左右子节点

```cpp
TreeNode* buildTree(vector<string>& vals) {
    if (vals.empty() || vals[0] == "null") return nullptr;
  
    TreeNode* root = new TreeNode(stoi(vals[0]));
    queue<TreeNode*> q;
    q.push(root);
  
    int i = 1;
    while (!q.empty() && i < vals.size()) {
        TreeNode* cur = q.front();
        q.pop();
      
        if (i < vals.size() && vals[i] != "null") {
            cur->left = new TreeNode(stoi(vals[i]));
            q.push(cur->left);
        }
        i++;
      
        if (i < vals.size() && vals[i] != "null") {
            cur->right = new TreeNode(stoi(vals[i]));
            q.push(cur->right);
        }
        i++;
    }
    return root;
}
```

### 4.3 二叉树的经典问题

#### ① 二叉树的垂序遍历

**问题**：按列从左到右输出节点值，同列同行按值排序

**核心思想**：DFS记录每个节点的(row, col)，按col分组，组内按row和val排序

**时间复杂度**：O(n log n)

```cpp
void dfs(TreeNode* node, int row, int col, 
         map<int, vector<pair<int, int>>>& colMap) {
    if (!node) return;
  
    colMap[col].push_back({row, node->val});
    dfs(node->left, row + 1, col - 1, colMap);
    dfs(node->right, row + 1, col + 1, colMap);
}

vector<vector<int>> verticalTraversal(TreeNode* root) {
    map<int, vector<pair<int, int>>> colMap;
    dfs(root, 0, 0, colMap);
  
    vector<vector<int>> result;
    for (auto& [col, nodes] : colMap) {
        sort(nodes.begin(), nodes.end());  // 先按row，再按val
        vector<int> colResult;
        for (auto& [row, val] : nodes) {
            colResult.push_back(val);
        }
        result.push_back(colResult);
    }
    return result;
}
```

**关键点**：

- 使用 `map`自动按col排序
- `pair<int, int>`默认先比较first（row），再比较second（val）

#### ② 二叉树的最大路径和

**问题**：找到树中任意节点间的路径，使路径上节点值之和最大

**核心思想**：后序遍历，对每个节点计算：

1. 作为路径最高点的最大路径和（可以走左右两边）
2. 向父节点返回的最大贡献（只能走一边）

**时间复杂度**：O(n)

```cpp
class Solution {
    int ans = INT_MIN;
  
    int dfs(TreeNode* root) {
        if (!root) return 0;
      
        // 左右子树的最大贡献（负数则不选）
        int leftGain = max(0, dfs(root->left));
        int rightGain = max(0, dfs(root->right));
      
        // 当前节点作为路径最高点
        int curPathSum = root->val + leftGain + rightGain;
        ans = max(ans, curPathSum);
      
        // 返回给父节点的贡献（只能选一边）
        return root->val + max(leftGain, rightGain);
    }
  
public:
    int maxPathSum(TreeNode* root) {
        dfs(root);
        return ans;
    }
};
```

**关键点**：

- `max(0, ...)`：如果子树贡献为负，不如不走
- 全局变量 `ans`记录最大路径和
- 返回值是单边最大贡献

#### ③ 最近公共祖先（LCA）

**方法一：父指针法（适用于有父指针的树）**

**思路**：标记x的所有祖先，然后从y向上找第一个被标记的节点

**时间复杂度**：O(h)，h为树高

```c
// 标记x的祖先
int t = x;
while (t != 0) {
    visited[t] = 1;
    t = parent[t];
}

// 从y向上找
t = y;
while (t != 0) {
    if (visited[t]) {
        printf("%d\n", t);  // 找到LCA
        break;
    }
    t = parent[t];
}
```

**方法二：递归法（通用）**

```cpp
TreeNode* lowestCommonAncestor(TreeNode* root, TreeNode* p, TreeNode* q) {
    if (!root || root == p || root == q) return root;
  
    TreeNode* left = lowestCommonAncestor(root->left, p, q);
    TreeNode* right = lowestCommonAncestor(root->right, p, q);
  
    if (left && right) return root;  // p、q在两侧
    return left ? left : right;      // 在同一侧
}
```

### 4.4 完全二叉树的节点个数

**优化方法**：利用完全二叉树的性质

```cpp
int countNodes(TreeNode* root) {
    if (!root) return 0;
  
    int leftHeight = 0, rightHeight = 0;
    TreeNode* l = root, *r = root;
  
    while (l) { leftHeight++; l = l->left; }
    while (r) { rightHeight++; r = r->right; }
  
    if (leftHeight == rightHeight) {
        return (1 << leftHeight) - 1;  // 满二叉树
    }
  
    return 1 + countNodes(root->left) + countNodes(root->right);
}
```

**时间复杂度**：O(log²n)

### 6.2 二分查找

**标准模板**：

```cpp
int binarySearch(vector<int>& nums, int target) {
    int left = 0, right = nums.size() - 1;
  
    while (left <= right) {
        int mid = left + (right - left) / 2;
        if (nums[mid] == target) return mid;
        else if (nums[mid] < target) left = mid + 1;
        else right = mid - 1;
    }
    return -1;
}
```

**关键点**：

- `mid = left + (right - left) / 2` 防止溢出
- 循环条件 `left <= right`

## 七、动态规划

### 7.1 DP解题步骤

1. **确定状态**：定义dp数组的含义
2. **确定转移方程**：找出状态之间的关系
3. **确定初始条件**：边界情况
4. **确定计算顺序**：自底向上或自顶向下

### 7.2 经典DP问题

#### ① 爬楼梯

**问题**：每次可以爬1或2阶，爬到n阶有多少种方法？

**状态定义**：`dp[i]`表示爬到第i阶的方法数

**转移方程**：`dp[i] = dp[i-1] + dp[i-2]`

```cpp
int climbStairs(int n) {
    if (n <= 2) return n;
  
    int prev2 = 1, prev1 = 2;
    for (int i = 3; i <= n; i++) {
        int curr = prev1 + prev2;
        prev2 = prev1;
        prev1 = curr;
    }
    return prev1;
}
```

**时间复杂度**：O(n)
**空间复杂度**：O(1)（滚动数组优化）

#### ② 打家劫舍

**问题**：不能抢劫相邻房屋，求最大收益

**状态定义**：`dp[i]`表示前i个房屋能抢到的最大值

**转移方程**：`dp[i] = max(dp[i-1], dp[i-2] + nums[i])`

```cpp
int rob(vector<int>& nums) {
    if (nums.empty()) return 0;
    if (nums.size() == 1) return nums[0];
  
    int prev2 = 0, prev1 = 0;
    for (int num : nums) {
        int curr = max(prev1, prev2 + num);
        prev2 = prev1;
        prev1 = curr;
    }
    return prev1;
}
```

#### ③ 最长递增子序列（LIS）

**状态定义**：`dp[i]`表示以nums[i]结尾的最长递增子序列长度

**转移方程**：`dp[i] = max(dp[j] + 1)`，其中 `j < i`且 `nums[j] < nums[i]`

```cpp
int lengthOfLIS(vector<int>& nums) {
    int n = nums.size();
    vector<int> dp(n, 1);
    int ans = 1;
  
    for (int i = 1; i < n; i++) {
        for (int j = 0; j < i; j++) {
            if (nums[j] < nums[i]) {
                dp[i] = max(dp[i], dp[j] + 1);
            }
        }
        ans = max(ans, dp[i]);
    }
    return ans;
}
```

**时间复杂度**：O(n²)
**优化**：二分查找可优化到O(nlogn)

## 八、回溯算法

### 8.1 回溯框架

```cpp
void backtrack(选择列表, 路径) {
    if (满足结束条件) {
        记录结果;
        return;
    }
  
    for (选择 in 选择列表) {
        做选择;
        backtrack(选择列表, 路径);
        撤销选择;  // 回溯
    }
}
```

### 8.2 经典回溯问题

#### ① 电话号码的字母组合

**问题**：给定数字字符串，返回所有可能的字母组合

**映射关系**：

- 2 → "abc"
- 3 → "def"
- ...

```cpp
const string phoneMap[] = {
    "", "", "abc", "def", "ghi", "jkl", 
    "mno", "pqrs", "tuv", "wxyz"
};

void backtrack(const string& digits, int index, string& current) {
    if (index == digits.length()) {
        cout << current << endl;
        return;
    }
  
    int digit = digits[index] - '0';
    const string& letters = phoneMap[digit];
  
    for (char c : letters) {
        current.push_back(c);           // 做选择
        backtrack(digits, index + 1, current);  // 递归
        current.pop_back();             // 撤销选择
    }
}
```

**时间复杂度**：O(3^m × 4^n)，m为对应3个字母的数字个数，n为对应4个字母的数字个数

#### ② 全排列

```cpp
void permute(vector<int>& nums, int start) {
    if (start == nums.size()) {
        result.push_back(nums);
        return;
    }
  
    for (int i = start; i < nums.size(); i++) {
```

#### ③ N皇后问题

**核心思想**：逐行放置皇后，检查列和对角线冲突

```cpp
bool isValid(vector<string>& board, int row, int col) {
    // 检查列
    for (int i = 0; i < row; i++) {
        if (board[i][col] == 'Q') return false;
    }
  
    // 检查左上对角线
    for (int i = row - 1, j = col - 1; i >= 0 && j >= 0; i--, j--) {
        if (board[i][j] == 'Q') return false;
    }
  
    // 检查右上对角线
    for (int i = row - 1, j = col + 1; i >= 0 && j < n; i--, j++) {
        if (board[i][j] == 'Q') return false;
    }
  
    return true;
}

void backtrack(vector<string>& board, int row) {
    if (row == board.size()) {
        result.push_back(board);
        return;
    }
  
    for (int col = 0; col < n; col++) {
        if (!isValid(board, row, col)) continue;
      
        board[row][col] = 'Q';          // 做选择
        backtrack(board, row + 1);      // 递归
        board[row][col] = '.';          // 撤销选择
    }
}
```

## 九、贪心算法

### 9.1 贪心策略

**核心思想**：每一步都做出局部最优选择，希望导致全局最优

**适用条件**：具有贪心选择性质和最优子结构

### 9.2 经典贪心问题

#### ① 跳跃游戏

**问题**：判断是否能到达最后一个位置

**贪心策略**：维护最远可达位置

```cpp
bool canJump(vector<int>& nums) {
    int maxReach = 0;
    for (int i = 0; i < nums.size(); i++) {
        if (i > maxReach) return false;  // 当前位置不可达
        maxReach = max(maxReach, i + nums[i]);
        if (maxReach >= nums.size() - 1) return true;
    }
    return true;
}
```

#### ② 买卖股票的最佳时机

**问题**：只能交易一次，求最大利润

**贪心策略**：记录历史最低价，每天计算潜在利润

```cpp
int maxProfit(vector<int>& prices) {
    int minPrice = INT_MAX;
    int maxProfit = 0;
  
    for (int price : prices) {
        minPrice = min(minPrice, price);
        maxProfit = max(maxProfit, price - minPrice);
    }
    return maxProfit;
}
```

**时间复杂度**：O(n)

```cpp
struct TrieNode {
```

**插入操作**：

```cpp
void insert(string word) {
    TrieNode* node = root;
    for (char c : word) {
        int idx = c - 'a';
        if (!node->children[idx]) {
            node->children[idx] = new TrieNode();
        }
        node = node->children[idx];
    }
    node->isEnd = true;
}
```

**搜索操作**：

```cpp
bool search(string word) {

        node = node->children[idx];

}
```

### 10.2 LRU缓存

**要求**：

- `get(key)`：O(1)时间
- `put(key, value)`：O(1)时间
- 容量满时淘汰最久未使用的

**实现**：哈希表 + 双向链表

```cpp
class LRUCache {
    struct Node {
        int key, value;
        Node* prev, *next;
        Node(int k, int v) : key(k), value(v), prev(nullptr), next(nullptr) {}
    };
  
    unordered_map<int, Node*> cache;
    Node* head, *tail;
    int capacity, size;
  
    void addToHead(Node* node) {
        node->prev = head;
        node->next = head->next;
        head->next->prev = node;
        head->next = node;
    }
  
    void removeNode(Node* node) {
        node->prev->next = node->next;
        node->next->prev = node->prev;
    }
  
    void moveToHead(Node* node) {
        removeNode(node);
        addToHead(node);
    }
  
public:
    LRUCache(int capacity) : capacity(capacity), size(0) {
        head = new Node(0, 0);
        tail = new Node(0, 0);
        head->next = tail;
        tail->prev = head;
    }
  
    int get(int key) {
        if (!cache.count(key)) return -1;
        Node* node = cache[key];
        moveToHead(node);
        return node->value;
    }
  
    void put(int key, int value) {
        if (cache.count(key)) {
            Node* node = cache[key];
            node->value = value;
            moveToHead(node);
        } else {
            Node* newNode = new Node(key, value);
            cache[key] = newNode;
            addToHead(newNode);
            size++;
          
            if (size > capacity) {
                Node* removed = tail->prev;
                removeNode(removed);
                cache.erase(removed->key);
                delete removed;
                size--;
            }
        }
    }
};
```
