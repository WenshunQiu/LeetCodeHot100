## 2026_3_20 — 链表与集合运算

### 1. 带头节点单链表：在第一个最大值节点前插入节点
- 先遍历链表找最大值 `max`。
- 再次遍历找到第一个值等于 `max` 的节点，记录其前驱 `pre`。
- 新节点 `newNode` 插入：`newNode->next = p; pre->next = newNode;`。
- 注意：链表可能存在多个最大值节点，要求在第一个最大值之前插入。

### 2. 单链表集合差集运算 `C = A - B`
#### 无序链表差集
- 遍历 `A`，对每个元素调用 `IsExist(B, x)`。
- 若在 `B` 中存在，则从 `A` 中删除该结点并释放内存。
- 时间复杂度 `O(n*m)`，空间复杂度 `O(1)`。

#### 有序链表差集
- 使用双指针 `pa`、`pb`，类似归并操作。
- 若 `pa->data < pb->data`，`pa` 前进；若相等，删除 `pa`；否则 `pb` 前进。
- 时间复杂度 `O(n+m)`，空间复杂度 `O(1)`。

### 3. 查找链表倒数第 k 个节点
- 题目 `S7.c` 使用先统计长度 `len`，然后走 `len - k` 步得到目标节点。
- 还有一种常见方法：双指针法，先让快指针先走 `k` 步，然后快慢指针同步前进。

### 4. 链表中处理最大值节点
- `S4.cpp` 将值最大的节点移到尾部。
- 需要记录最大节点 `max` 以及它的前驱 `premax`，并修正指向。
- 特别处理：最大节点是头节点或尾节点的情况。

### 5. 双向循环链表的插入/删除与约瑟夫问题
- `S5.cpp` 实现循环双链表操作，支持按位置插入和删除。
- `S6.cpp` 将普通单链表变为循环链表，模拟约瑟夫出列过程，最终生成新队列。

### 6. 其他重要点
- 链表初始化：带头结点和无头结点的区别。
- 链表遍历与释放内存。
- 头插法 / 尾插法构造单链表。

## 2026_3_26 — 栈、表达式、路径与递归模拟

### 1. 直方图最大矩形 `biggest_rect.cpp`
- 典型单调栈算法。
- 用下标入栈，保持栈内高度呈递增序列。
- 当前高度小于栈顶高度时，弹出栈顶，计算矩形面积：`height * width`。
- 最后一轮加入高度 `0` 强制清空栈。

### 2. 中缀表达式求值 `cal.c`
- 使用操作符栈和操作数栈。
- 通过优先级函数 `getPriority(op)` 判断运算顺序。
- 遇到 `(` 直接入栈；遇到 `)` 时弹出直到匹配 `(`。
- 支持 `+ - * / %`。

### 3. 函数调用关系解析 `funcall.c`
- 用栈模拟函数调用栈。
- 输入操作码 `5` 表示函数进入，`0` 表示函数返回。
- 记录每个函数调用的子函数，避免重复。
- 最终输出调用图：`parent:child1;child2;...`。

### 4. 栈出栈序列验证与弹出次数 `max_pop.c`
- 先读入入栈序列 `in[]`，和出栈序列 `out[]`。
- 模拟入栈，同时在可能的情况下进行出栈对比。
- 若最后完全匹配，则输出出栈次数；否则输出 `0`。

### 5. 迷宫/路径搜索与栈模拟
- `migon.c` 使用显式栈实现 DFS 迷宫搜索，记录每个节点的方向状态。
- `path.c` 和 `minpath.c` 都是路径简化题：
  - 合并同方向步数。
  - 抵消相反方向步数。
  - 使用栈解决相邻方向抵消问题。

### 6. 模拟递归的栈帧 `simu_product.c`
- 通过显式栈 `SeqStack` 模拟递归调用过程。
- 每个栈帧保存 `n` 和状态字符串（如 `n*?`、`Calculate product`）。
- 这是“递归转栈”的经典思路。

## 2026_4_10 — 链表递归、动态规划、字符串、回溯

### 1. 链表递归与递归输出 `1.cpp`
- `InitList` 采用尾插法构造带头结点链表。
- `inverseprint` 使用递归从尾到头打印链表。

### 2. 子序列计数 DP `2.cpp`
- 统计 `t` 在 `s` 中出现的子序列个数。
- 经典一维 `dp[j]`：`dp[j] += dp[j-1]` 当 `s[i]==t[j-1]`。

### 3. 无头单链表尾插构造 `3.cpp`
- 使用 `L == NULL` 作为空表判断。
- 尾插法构造无头单链表。

### 4. 回文对与字符串查找 `4.cpp`、`5.cpp`
- 利用哈希表把每个字符串映射到索引。
- 对每个单词尝试所有分割点：`left` / `right`。
- 若 `left` 是回文且 `reverse(right)` 在表中，则构成回文对。
- 这类题目考察字符串分割、回文判断、反转与哈希映射。

### 5. 字母异位词分组 `groupAnagrams.cpp`
- 先对字符串排序作为 key。
- 用 `unordered_map<string, vector<string>>` 聚合同字母异位词。

### 6. 电话号码字母组合 `phonenum_dfs.cpp` / `phonenum.c`
- DFS 回溯生成所有字母组合。
- 也可用固定层数的嵌套循环模拟。
- 栈/递归回溯的基本写法：
  - 选择一种字符加入当前字符串
  - 递归处理下一位
  - 回溯撤销选择

### 7. 火车调度/栈模拟 `train.c`
- 题目使用栈模拟货物装载与目的地判断。

## 2026_4_17 — 二叉树基础与特殊树算法

### 1. 统计树节点数 `CompleteTreesNode.c`
- 解析形如 `[1,2,3,null,4]` 的层序字符串。
- 统计非 `null` 节点数量。

### 2. 层序构建二叉树 `ExtractTrees.c` / `ReverseTrees.c` / `verticalTraversal.cpp`
- 使用队列按层序创建树。
- `null` 节点用特殊标记表示缺失子节点。
- 这类题目常见输入解析与 BFS 建树技巧。

### 3. 最近公共祖先 `LCA.c`
- 读边构建父指针数组 `parent[v] = u`。
- 从 `x` 向上标记所有祖先。
- 从 `y` 向上第一个已标记节点即为 LCA。

### 4. 二叉树距离 K 节点 `node.cpp`
- 先找到 `root` 到 `target` 的路径。
- `collect(target, k)` 收集 target 子树中距离为 `k` 的节点。
- 处理上层祖先：如果向上距离为 `d < k`，则搜集另一支子树中距离 `k-d-1` 的节点。
- 这是“树上距离/路径”的经典解法。

### 5. 二叉树垂直遍历 `verticalTraversal.cpp`
- 解析层序输入，建立树结构。
- 使用 `map<column, vector<...>>` 存储不同列。
- 按列号、层序、节点值排序输出。

### 6. 合并树 / 树字符串解析 `MergeTrees.cpp`
- 题目范围：字符串解析、节点合并、树结构构建。
- 需要熟悉各种树输入格式与手动解析。

## 2026_4_24 — 树形题目与树上 DP

### 1. 先序 + 中序重建二叉树 `buildtree.cpp`
- 先序第一个节点为根。
- 在中序中定位根节点，划分左右子树。
- 递归构建左子树和右子树。
- 使用哈希表记录中序值的位置，避免重复遍历。

### 2. 员工重要性 DFS `importance.cpp`
- 解析嵌套 `employees` 数据结构。
- 以 `id` 建立 `unordered_map<int, Employee*>`。
- DFS 求和当前员工及其所有下属的重要性。

### 3. 最大二叉树 `maxtree.cpp`
- 数组中取最大值作为根。
- 递归构造左区间和右区间子树。
- 这是“分治 + 递归建树”的典型例题。

### 4. 二叉树最大路径和 `maxway.cpp`
- 后序遍历计算左右子树贡献 `leftGain` / `rightGain`。
- 当前路径和 `root->val + leftGain + rightGain` 更新全局最大值。
- 返回值是 `root->val + max(leftGain, rightGain)`。
- 关键是负贡献舍去 `max(0, dfs(...))`。

### 5. 最大搜索二叉树子树和 `maxsunbst.cpp`
- 后序遍历返回三元组 `{min, max, sum}`。
- 判断当前子树是否是 BST：`left.max < root.val < right.min`。
- 若是，则更新最大 BST 和。

### 6. 二叉树转双向链表 `TreetoList.cpp`
- 中序遍历构建链表。
- `pre` 记录前驱节点，`head` 记录链表头。
- 最后连接头尾，形成双向循环链表。

### 7. 字符串解析与节点构造工具 `Serialization.cpp` / `useful.cpp`
- 解析类似 `root = [...]` 或 `[...]` 的输入字符串。
- 这是处理树结构输入题时常见的预处理技巧。
