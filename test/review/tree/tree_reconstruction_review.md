## 第1题：带回溯标记的多叉树DFS序列重构 + 层序统计每层节点数
### 题目描述
多叉树结点定义如下，每个节点可包含任意数量子节点：
```cpp
struct Node {
    int data;
    vector<Node*> children;
    Node(int x) : data(x) {}
};
```

**DFS序列化规则（先根遍历）**：
1. 访问当前节点，记录节点值；
2. 按顺序递归遍历每一棵子树；
3. 当前节点所有子树遍历完成后，插入标记 `-1` 表示回溯、子树结束。

示例树与对应序列化序列：
```
        1
     /   |   \
    2    3    4
    |
    5
```
序列：`[1, 2, 5, -1, -1, 3, -1, 4, -1, -1]`

**要求**：
1. 给定序列化数组，用**递归算法**重构多叉树；
2. 使用 `std::queue` 对重构后的树进行层序遍历，输出每一层的节点数量；
3. 分析算法时间复杂度。

### 实现思路
1. **重构核心逻辑**
    - 用一个**引用传递的下标指针** `idx` 全局控制序列读取进度；
    - 读取当前位置数值作为新节点，`idx` 后移；
    - 循环读取后续序列：只要当前值不是 `-1`，就递归构建子节点并加入当前节点的 `children`；
    - 遇到 `-1` 说明当前节点子树全部构建完毕，`idx` 后移并返回当前节点。

2. **层序统计每层节点数**
    - 队列存储节点，每层开始前记录队列大小 `size`，即为当前层节点数；
    - 遍历当前层所有节点，将其子节点全部入队，进入下一层循环。

### 完整代码实现
见文件：`multi_tree_dfs_reconstruct.cpp`

### 复杂度&易错点
- **时间复杂度**：$O(n)$，每个节点、每个标记仅访问一次；
- **空间复杂度**：$O(h)$ 递归栈深度，最坏退化为链表 $O(n)$；
- **易错点**：
  1. `idx` 必须引用传递，否则递归返回后下标无法全局推进；
  2. 构建完所有子节点后，必须跳过当前节点对应的 `-1` 回溯标记；
  3. 多叉树无左右孩子，子节点全部存入 `vector`，遍历需用循环。

## 第2题：层序序列化序列重构二叉树 + 求树最大宽度
### 题目描述
二叉树结点定义：
```cpp
struct BTNode {
    int data;
    BTNode *lchild, *rchild;
    BTNode(int x) : data(x), lchild(nullptr), rchild(nullptr) {}
};
```

**层序序列化规则**：按从上到下、从左到右的顺序记录节点，空节点用字符 `#`（数值用 `-1` 代替）标记。
示例树：
```
           1
         /   \
        3     2
       / \     \
      5   3     9
```
层序序列：`[1, 3, 2, 5, 3, -1, 9]`

**要求**：
1. 仅使用 `std::queue`，以**迭代方式**重构二叉树（禁止递归）；
2. 基于重构后的二叉树，计算树的最大宽度（宽度定义：每层最左、最右非空节点编号差+1，中间空节点计入宽度；根编号为1，左孩子 `2*idx`，右孩子 `2*idx+1`）；
3. 说明编号变量不能用 `int` 的原因，并给出优化方案。

### 实现思路
1. **层序迭代重构核心**
    - 序列首元素为根节点，创建根并入队；
    - 用下标 `idx` 从1开始遍历序列，每次取出队首父节点；
    - 先处理左孩子：若当前序列值不为 `-1`，创建左节点、挂到父节点、入队；`idx` 后移；
    - 再处理右孩子：逻辑同上；
    - 空节点仅跳过下标，不入队。

2. **最大宽度计算**
    - 队列存储 `(节点, 编号)` 二元组，层序遍历；
    - 每层开始记录最左节点编号，每层遍历结束记录最右编号，计算 `right - left + 1` 更新最大值；
    - 编号用 `unsigned long long` 防止深层树溢出。

### 完整代码实现
见文件：`level_order_reconstruct_max_width.cpp`

### 复杂度&易错点
- **时间复杂度**：重构 $O(n)$，求宽度 $O(n)$，整体 $O(n)$；
- **空间复杂度**：队列最大存储一层节点，最坏 $O(n)$；
- **易错点**：
  1. 处理完左右孩子后，无论是否为空，`idx` 都必须后移；
  2. 宽度计算必须在**每层遍历结束后**进行，不能提前计算；
  3. 编号必须用 `unsigned long long`，树深度超过30层时 `int` 会溢出。

## 第3题：后序+中序 原地下标重构二叉树 + 迭代前序遍历
### 题目描述
二叉树结点定义同上，给定无重复元素的**后序遍历序列** `post[]` 和**中序遍历序列** `in[]`。
**要求**：
1. 递归重构二叉树，**禁止创建子数组切片**，仅通过左右下标区间划分子树（原地空间优化）；
2. 使用 `std::stack` 实现**迭代版前序遍历**，输出所有节点值；
3. 说明：若序列存在重复节点值，为什么无法唯一重构二叉树。

### 实现思路
1. **原地下标重构核心**
    - 后序序列的**最后一个元素**是当前子树的根节点；
    - 在中序序列中找到根的位置 `rootIdx`，左侧为左子树，右侧为右子树；
    - 计算左子树长度 `leftLen = rootIdx - inL`；
    - 递归左子树：中序区间 `[inL, rootIdx-1]`，后序区间 `[postL, postL + leftLen - 1]`；
    - 递归右子树：中序区间 `[rootIdx+1, inR]`，后序区间 `[postL + leftLen, postR-1]`。

2. **迭代前序遍历**
    - 根节点先入栈；
    - 循环弹出栈顶节点并访问；
    - 先压入右孩子、再压入左孩子（栈后进先出，保证左孩子先访问）。

### 完整代码实现
见文件：`post_inorder_reconstruct_preorder_iterative.cpp`

### 复杂度&易错点
- **时间复杂度**：最坏 $O(n^2)$（每次线性找根，树退化为链表）；可用哈希表预处理中序值与下标映射，优化为 $O(n)$；
- **空间复杂度**：$O(h)$ 递归栈，无额外数组空间；
- **易错点**：
  1. 后序右边界是 `postR-1`，因为最后一个元素是根，已经被使用；
  2. 左子树后序区间长度必须和中序左子树长度严格一致，边界计算容易写错。

## 第4题：中序线索二叉树构建 + 无栈中序遍历
### 题目描述
中序线索二叉树结点定义：
```cpp
struct ThreadNode {
    int data;
    ThreadNode *lchild, *rchild;
    bool ltag, rtag; // 0：指针指向孩子；1：指针指向前驱/后继线索
    ThreadNode(int x) : data(x), lchild(nullptr), rchild(nullptr), ltag(0), rtag(0) {}
};
```

**要求**：
1. 给定二叉树前序、中序序列，先重构二叉树骨架；
2. 将二叉树转化为**中序线索二叉树**，为空指针填充前驱、后继线索；
3. 不使用栈、不递归，仅依靠线索实现整棵树的中序遍历并输出。

### 实现思路
1. **二叉树骨架重构**：使用前序+中序常规递归方式构建基础二叉树结构。
2. **中序线索化核心**
    - 用全局指针 `preNode` 记录上一个访问的节点；
    - 中序遍历过程中：
      - 若当前节点左孩子为空，设置 `ltag=1`，`lchild` 指向 `preNode`（前驱）；
      - 若 `preNode` 不为空且 `preNode` 右孩子为空，设置 `preNode->rtag=1`，`preNode->rchild` 指向当前节点（后继）；
      - 更新 `preNode` 为当前节点。
3. **线索化中序遍历**
    - 从根出发，循环找到最左节点（第一个访问节点）；
    - 循环访问当前节点：
      - 若 `rtag=1`，直接走 `rchild` 即为下一个后继节点；
      - 若 `rtag=0`，进入右子树，找到右子树的最左节点作为下一个访问节点。

### 完整代码实现
见文件：`threaded_binary_tree.cpp`

### 复杂度&易错点
- **时间复杂度**：构建 $O(n)$，线索化 $O(n)$，遍历 $O(n)$；
- **空间复杂度**：线索化递归栈 $O(h)$，遍历过程 $O(1)$ 额外空间；
- **易错点**：
  1. 线索化前必须重置 `preNode` 为 `nullptr`，否则首节点前驱会出错；
  2. 仅当指针为空时才设置为线索，原有孩子指针不能修改；
  3. 遍历到右子树时，必须循环找到最左节点，不能直接访问右孩子。

## 第5题：森林（孩子兄弟表示法）重构 + 森林还原 + 层序输出
### 题目描述
孩子兄弟表示法二叉树结点定义：
```cpp
struct CSNode {
    int data;
    CSNode *firstchild;  // 第一个孩子
    CSNode *nextsibling; // 下一个兄弟
    CSNode(int x) : data(x), firstchild(nullptr), nextsibling(nullptr) {}
};
```

**规则**：
- 森林的**先根遍历序列** = 对应孩子兄弟二叉树的**前序遍历序列**；
- 森林的**后根遍历序列** = 对应孩子兄弟二叉树的**中序遍历序列**。

**要求**：
1. 给定森林的先根序列、后根序列，重构出**孩子兄弟表示法的二叉树**；
2. 将孩子兄弟二叉树还原为原始森林，输出森林中树的数量；
3. 对森林中每一棵树进行层序遍历，输出各层节点值。

### 实现思路
1. **孩子兄弟二叉树重构**
    - 等价于「前序+中序重构二叉树」，前序是森林先根序列，中序是森林后根序列；
    - 前序首元素为根，中序中找到根位置，左侧为第一棵子树的所有节点，右侧为兄弟树的所有节点。

2. **森林还原核心**
    - 孩子兄弟二叉树中，根节点的右链上的所有节点，都是森林中每一棵树的根；
    - 遍历根的右链，逐个断开 `nextsibling` 指针，每个节点作为一棵树的根存入森林数组。

3. **每棵树的层序遍历**
    - 对每个树根，队列存储节点，先输出当前节点，再将所有孩子（沿 `firstchild` 向右遍历所有兄弟）入队。

### 完整代码实现
见文件：`forest_cs_reconstruct.cpp`

### 复杂度&易错点
- **时间复杂度**：重构 $O(n)$，还原 $O(n)$，层序遍历 $O(n)$；
- **空间复杂度**：递归栈 $O(h)$，队列最坏 $O(n)$；
- **易错点**：
  1. 孩子兄弟二叉树中，`firstchild` 对应二叉树左孩子，`nextsibling` 对应二叉树右孩子，不要混淆；
  2. 层序遍历时，孩子节点需要沿 `nextsibling` 链遍历全部，不能只访问第一个孩子；
  3. 还原森林时，必须断开兄弟指针，否则树与树之间仍有连接。

## 总结与备考建议

### 核心考点归纳
1. **递归下标推进技术**：第1、3、4、5题均使用引用传递的下标指针控制序列读取，这是树重构的核心技巧
2. **空间优化思维**：第3题强调"原地下标"而非数组切片，考察对递归参数设计的理解
3. **数据结构转换能力**：第4题（线索化）、第5题（森林↔二叉树）考察不同树表示法之间的转换
4. **迭代替代递归**：第2题（层序重构）、第3题（迭代前序）、第4题（无线索遍历）考察栈/队列的应用

### 易错点汇总
| 题型 | 关键易错点 | 解决方案 |
|------|-----------|---------|
| 多叉树重构 | idx未引用传递 | 函数参数用 `int& idx` |
| 层序重构 | 空节点idx未后移 | 无论是否创建节点，idx都要++ |
| 后序+中序 | 后序右边界错误 | 右子树后序区间是 `[postL+leftLen, postR-1]` |
| 线索化 | preNode未初始化 | 线索化前执行 `preNode = nullptr` |
| 森林还原 | 未断开兄弟指针 | 还原时执行 `cur->nextsibling = nullptr` |

### 复习策略
1. **优先掌握**：第1题（多叉树）、第3题（后序+中序），这两题覆盖了80%的树重构考点
2. **重点突破**：第2题的最大宽度计算、第4题的线索遍历，属于高频拉分点
3. **理解本质**：第5题的森林转换，关键是理解"先根=前序，后根=中序"的映射关系

### 考试技巧
- 看到"重构"二字，首先判断给的是哪种遍历序列组合
- 递归重构时，画图确定左右子树的区间边界
- 涉及"最大宽度""最深深度"等统计问题，优先考虑层序遍历（BFS）
- 线索二叉树题目，牢记"左空指前驱，右空指后继"
